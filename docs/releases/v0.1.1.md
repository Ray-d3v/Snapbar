# Snapbar v0.1.1

Windows 11向けSnapbarの不具合修正版です。

## 主な修正

- Teamsの共有領域が縮小・移動したとき、古い範囲で撮影しないよう、撮影要求前・切り抜き時・出力前のUIA矩形とウィンドウの位置・サイズを照合します。要求前の確認より後に描画されたフレームだけを使い、確認できない場合はクリップボードを変更しません。
- 共有終了・撮影対象変更で無効化された撮影タスクが、後からクリップボードやPNGを書き込まないよう、共有世代と出力権限を確認して書き込み開始と同期します。
- 撮影時に確定したRGBA画像をクリップボード出力とPNG保存の共通データにし、保存処理でWindowsクリップボードを読み直さないようにします。
- Explorer再起動後も、非表示のトップレベル通知ウィンドウで`TaskbarCreated`を受信してトレイアイコンを再登録します。

## 配布ファイル

- `Snapbar-Setup-x64.exe`: ユーザー単位インストーラー
- `Snapbar-portable-x64.exe`: インストール不要の実行ファイル
- `Snapbar-SHA256SUMS.txt`: 配布ファイルのSHA-256チェックサム

コード署名は行っていないため、Windows SmartScreenの警告が表示される場合があります。

## 検証

自動テストとWindows release buildはGitHub Actionsで実行します。共有領域の縮小と撮影待機中の共有終了を対象にした回帰テストを追加しています。Windows 11上のTeams実機操作による検証は未実施です。

安全確認のため撮影ごとにUIAの確認と新しいフレーム取得を行います。静止画でフレームが届かない場合はセッションを一度作り直すため、撮影に時間がかかることがあります。
