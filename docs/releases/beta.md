Windows 11向けSnapbarのタイトルバー診断用ベータです。アイランド縮小の修正版ではありません。

PowerShellスクリプトを使わず、Snapbarを通常起動するだけで会議操作行の親要素・上部要素の配置を既存ログへ記録します。署名ポリシー変更、Add-Type、追加ランタイムのインストールは不要です。

## 取得手順

1. Snapbarを終了し、`Snapbar-Setup-x64.exe`を上書きインストールして起動します。
2. 同じTeams会議・同じ倍率のまま、共有前の正常状態と、デモONで共有中に小さくなった状態をそれぞれ30秒程度維持します。会議本体は最小化せず表示してください。
3. 通知領域のSnapbarを右クリックし「ログを開く」で取得したログを保存します。これまでのログと同じ形式で共有できます。

## 内容と制約

- `caption_tree_begin` / `caption_tree_node` / `caption_tree_end`を追加。原則30秒間隔、対象や直前の境界取得成否の変化時は最短5秒間隔です。
- 対象は選択中のTeamsウィンドウ。親の経路がそのウィンドウのルートに到達した場合のみ、親と上部の子要素を記録します。
- 診断は表示名・本文・画像・クリップボード内容を取得しません。AutomationIdは最大80文字で含まれます。識別子に動的な値が含まれる可能性があるため、共有前にログを確認してください。外部送信はしません。
- 探索の階層・件数・ログ量と、呼び出し間の時間予算を制限します。単一のUIA呼び出しは中断できず、500ms以内に必ず終了する保証はありません。タイトルバーの色・倍率確認が診断中に遅れる可能性はあります。撮影エンジンやネイティブの追従・ホバー処理へ診断を追加していません。
- 倍率、配置、共有範囲、出力認可の判定は変更しません。診断結果は配置に使わず、終了後に既存の境界確認を再実行します。

スクリプト実行エラーの原因を変更して回避するものではなく、そのスクリプト自体を必要としない診断経路です。配布ファイルのコード署名は従来どおりありません。Windowsのアプリ実行制限がある場合は管理者の運用に従ってください。
