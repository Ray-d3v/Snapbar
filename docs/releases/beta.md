Windows 11向けのSnapbarベータビルドです。

- デモON・自分の画面共有中に追加される会議タイトルバーUIについて、倍率検出の候補を取りこぼすコードを修正しました。既知の会議操作領域をAutomationIdで探索し、要素種類や名前取得失敗を理由に除外しないようにしています。通常のタイトルバーUIにも同じ修正を適用します。
- 非表示・無効・曖昧な矩形の拒否、異なる2種類以上の操作領域の一致、取得前後のウィンドウ・DPI確認は維持します。倍率の固定や古い座標の無条件再利用は行いません。
- 境界が取れない場合を切り分けるcaption_probe診断ログと、検索条件・名前欠落・非表示要素を扱う6件の回帰テストを追加しました。ログに会議名・会議本文・要素の名前は保存しません。

実端末のTeamsで症状が解消したかは未確認です。旧ログには失敗した候補の種類・表示状態・矩形がないため、今回修正した取りこぼしが症状の唯一の原因とは断定できません。Teamsが境界候補自体を公開しない場合は、従来どおりDWMによる配置へ戻るため、内部ズームへの追従ができない場合があります。

撮影エンジン、共有範囲の安全確認、クリップボード保護、デモの録画可否、ホバー状態機械は変更していません。

`Snapbar-Setup-x64.exe` がインストーラーです。
