Windows 11向けのSnapbarベータビルドです。

- Teamsの変更通知で撮影の確認要求が詰まる問題を軽減。通知を集約し、撮影確認をフレーム更新・定期探索より優先します。
- 期限切れの確認要求をUI Automation処理前に破棄します。
- ローカル監査ログへ変更通知の種類別件数、確認の待ち時間・実行時間、再探索の理由を追加しました。
- デモ用の補助UIを必要時だけ生成し、タイトルバー全探索と不要な再描画を削減しました。
- クリップボード再試行の待機中に撮影認可ロックを解放します。

Teams側で実行中のUI Automation呼び出しは中断できないため、すべての端末で応答遅延の解消を保証するものではありません。共有領域の確認に失敗した場合は撮影を停止し、クリップボードを変更しません。

`Snapbar-Setup-x64.exe` がインストーラー、`Snapbar-portable-x64.exe` がポータブル版です。
