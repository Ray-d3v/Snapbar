Windows 11向けのSnapbarベータビルドです。

- 他参加者共有で、取得失敗により画像キャッシュが失われ、その後フレーム到着が5秒以上止まった場合に、常駐処理から撮影セッションの復旧を試みるよう修正しました。UIAが回復してもオレンジ状態から戻らない経路を対象にしています。
- 正常な静止画像、フレーム到着が続いている一時的なUIA失敗、撮影・事前確認中には、この自動復旧を適用しません。
- 以前のネイティブ停止が未完了なら追加の自動ストール復旧を抑え、停止待ち処理の蓄積を防ぎます。
- 復旧理由とフレーム停止時間をログへ追加し、10件の回帰テストを追加しました。UIやホバー・DPI配置は変更していません。

共有領域のUIA再検証と、確認できない場合の撮影停止・クリップボード保護は維持します。単一のUIA呼び出しやOS側の長時間停止そのものを解消する修正ではなく、全遅延の解消や5秒以内の復旧を保証するものではありません。

`Snapbar-Setup-x64.exe` がインストーラーです。
