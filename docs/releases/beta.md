Windows 11向けのSnapbarベータビルドです。

- 変更のない定期監査の2回の走査を分離し、走査間の待機中と再開時に撮影要求を優先します。
- 高速撮影でも出力直前に共有領域を再検証し、検証中のフレーム更新を確認します。
- 診断ログに定期監査の各走査時間と高速撮影の拒否理由を追加しました。

全候補の2回確認と、共有領域を確定できない場合の撮影停止・クリップボード保護を維持しています。実行中の単一UI Automation呼び出しは中断できず、別端末での遅延改善幅は再測定が必要です。

`Snapbar-Setup-x64.exe` がインストーラー、`Snapbar-portable-x64.exe` がポータブル版です。
