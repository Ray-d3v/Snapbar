Windows 11向けのSnapbarベータビルドです。

- UIAによる共有領域の確認失敗だけでは、動作中の撮影セッションを常駐処理から再起動しないよう修正しました。終了・起動失敗時の再試行は維持します。
- 定期監査の走査エラーと背景確認の失敗理由を記録します。
- 常駐処理の再起動と撮影操作時の復旧を区別し、復旧時のエラーとエンジン状態を記録します。

共有領域を確定できない場合の撮影停止・クリップボード保護は維持します。撮影時の復旧やフレーム保持の改善は残っており、全遅延の解消を保証するものではありません。

`Snapbar-Setup-x64.exe` がインストーラーです。
