# Snapbar

Snapbar is a lightweight Windows 11 utility that captures a Microsoft Teams shared-screen window and copies the latest frame to the clipboard with one click.

The application is intentionally manual-launch and non-resident: start it when needed, capture repeatedly from the floating bar, and close it to terminate the process completely.

> Initial implementation in progress: Rust + GPUI UI, Windows Graphics Capture through `xcap`, clipboard-only output.
